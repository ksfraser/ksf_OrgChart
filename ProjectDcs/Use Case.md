# Use Cases - ksf_OrgChart

## UC-OC-001: View Org Chart
**Actor**: Any Employee

**Flow**:
1. Navigate to Org Chart
2. View hierarchical tree of organization
3. Click on employee to see details
4. Filter by department, location

## UC-OC-002: Update Reporting Line
**Actor**: HR Manager

**Flow**:
1. Navigate to employee
2. Change manager assignment
3. Org chart updates automatically
4. ksf_Leave, ksf_Workflow notified of change
